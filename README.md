# 星穹工厂 V1.0 · 挂机自动化

> DSP（戴森球计划）风格的 2D 工厂自动化挂机游戏。零依赖纯 HTML/JS + Canvas 2D，单文件可双击运行。

## 功能特性

- **81 种物品** — 矿物、材料、零件、化工品、电子器件、燃料、戴森组件、物流、科研矩阵、增产剂
- **81 条配方** — 从铁矿石到戴森球的完整生产链
- **38 种建筑** — 采矿机、制造台、精炼厂、化工厂、喷涂机、传送带（3级）、分拣器、发电站、研究站、物流站、戴森发射器等（建造消耗材料；拆下的建筑进全局建筑卡池，任意星球都能免材料重建。解锁星际物流后，建造还能取用其他星球的库存，新殖民地不必从零运建材）
- **70 项科技** — DAG 前置关系 + 分列科技树，可排队研究（同时只推进一个）
- **8 星系 / 22 行星** — 行星矿种互补（启明 I 出水油石、焰砾 II 出硅钛），中后期必须靠物流站跨星双向运货；各星独立产线，后台持续推进
- **图鉴（三分区）** — 物品（天然来源 / 生产方式 / 作为原料 / 科研用途）、建筑（成本 / 属性 / 适用配方）、星球（环境 / 日照 / 矿种），条目之间可互相跳转
- **节点方块模型** — 建筑可叠加、类型化端口连线、块内信息卡片
- **增产剂系统** — 喷涂机绑定产线，额外产出 / 加速两种模式（矩阵只能加速）
- **反物质链** — 射线接收站吃戴森云，火电/聚变/人造恒星需持续供燃料
- **戴森球规划器** — 3 轨 × 12 槽球面编辑器，节点可放置/移动/拆除
- **离线挂机** — 关闭后自动结算离线产出（上限 8 小时），回来即收
- **双语 UI** — 简体中文 / English
- **移动端适配** — 双指缩放、可折叠侧栏、Pointer Events 统一交互
- **开局直送产线** — 新档在回收库赠送可直接生产电磁矩阵的矿→炼→造→研产线建筑（含 6 台制造台），开局即可上手
- **库存拖投** — 桌面端把库存物品直接拖到画布建筑卡上手动投料
- **明亮主题** — 白底彩色卡片风格，默认配色

## 快速开始

### 方式一：直接运行（无需 Node.js）

双击 `dist/dsp-factory.html`（约 577KB 单文件），用浏览器打开即可。

🔗 **在线试玩**（GitHub Pages）：整站 `https://mclovezy.github.io/factory-game/`；单文件版 `https://mclovezy.github.io/factory-game/dist/dsp-factory.html`

### 方式二：本地开发

```bash
cd factory-game
npm start          # 启动本地开发服务器
```

浏览器打开 `http://localhost:8080`（端口以终端输出为准）。

## 开发命令

```bash
npm test              # 运行全部测试（node --test）
npm run build:single  # 构建单文件到 dist/dsp-factory.html
```

## 项目结构

```
factory-game/
├── dist/dsp-factory.html   # 构建产物（单文件，可双击运行）
├── src/                     # 源码（9 个模块，经典脚本 + globalThis）
├── styles/main.css          # 样式
├── tests/                   # 测试（node --test）
├── scripts/                 # 开发服务器 + 单文件构建
└── index.html               # 开发入口
```

## 技术亮点

- **零 npm 依赖** — 纯原生 JS + Canvas，无框架无构建工具
- **经典脚本 + globalThis** — 兼容浏览器 file:// 与 Node 冒烟测试
- **单文件构建** — 9 个 JS + 1 个 CSS 内联为 1 个 HTML，方便发布
- **确定性模拟** — 种子随机（xmur3 + mulberry32），可重放
- **localStorage 存档** — 单一自动存档 + 导入/导出 JSON

## 技术栈

| 层级 | 选型 |
|------|------|
| 渲染 | Canvas 2D |
| 交互 | Pointer Events（鼠标 + 触摸统一） |
| 存档 | localStorage（key 前缀 `dspFactory.`） |
| 模拟 | 固定步长 20Hz + requestAnimationFrame |
| 测试 | Node.js 内置 `node --test` |
| 构建 | Node.js 脚本（内联打包） |
